# Customer Behaviour AI

An AI-powered Customer Behaviour Analysis application built using Python, Machine Learning, and Streamlit to analyze customer data, identify behavioural patterns, and generate useful business insights.

## Project Overview

Customer Behaviour AI helps businesses understand customer preferences, purchasing patterns, and engagement through data analysis and machine learning.

The project aims to support data-driven business decisions and improve customer understanding.

## Key Features

- Customer data analysis and visualization
- Customer behaviour pattern identification
- Customer segmentation using Machine Learning
- Interactive dashboard using Streamlit
- AI-powered customer insights
- Data-driven business recommendations

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/customer_behaviour_ai.git
cd customer_behaviour_ai
```

**2. Create a virtual environment using uv**

```bash
uv venv
```

**3. Activate the environment (Windows)**

```bash
.venv\Scripts\activate
```

**4. Install dependencies**

```bash
uv pip install -r requirements.txt
```

**5. Run the application**

```bash
streamlit run app.py
```
